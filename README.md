# Customer Churn Prediction

Educational end-to-end project: predict whether a subscription (telco) customer will churn.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m src.data.download
jupyter notebook notebooks/01_eda.ipynb
```

## Dataset

IBM Telco Customer Churn (public sample). Download with `python -m src.data.download`.

See [PRD.md](PRD.md) for phased learning goals. Full documentation will be completed in the final phase.
